# Rust 字符串的常用方法与正确使用

Rust 中最常见的字符串类型是 `String` 和 `str`：

- `String` 是拥有所有权、可增长、堆分配的 UTF-8 字符串；
- `str` 是动态大小的 UTF-8 字符串切片，代码中通常以借用形式 `&str` 出现；
- 字符串字面量（如 `"hello"`）的类型是 `&'static str`。

```rust
let owned: String = String::from("hello");
let borrowed: &str = owned.as_str();
let literal: &'static str = "world";

assert_eq!(borrowed, "hello");
assert_eq!(literal, "world");
```

理解 `String`、`&str`、UTF-8 和所有权，是正确使用字符串方法的基础。

## 1. 创建字符串

### 1.1 创建空的 `String`

```rust
let mut text = String::new();
text.push_str("Rust");

assert_eq!(text, "Rust");
```

如果预先知道大致长度，可以使用 `with_capacity` 减少扩容：

```rust
let mut text = String::with_capacity(32);
text.push_str("hello");

assert!(text.capacity() >= 32);
```

容量以**字节**为单位，不是字符数量。

### 1.2 从 `&str` 创建 `String`

常见写法有三种：

```rust
let first = String::from("hello");
let second = "hello".to_owned();
let third = "hello".to_string();

assert_eq!(first, second);
assert_eq!(second, third);
```

对于 `&str`，`String::from` 和 `to_owned` 能更直接地表达“创建一个拥有所有权的字符串”。`to_string` 基于 `ToString`，还适用于数字等实现了 `Display` 的类型：

```rust
let number = 42;
assert_eq!(number.to_string(), "42");
```

### 1.3 从重复内容创建

```rust
let separator = "-".repeat(5);
assert_eq!(separator, "-----");
```

`repeat` 会分配新的 `String`。重复次数很大时，应考虑内存使用和输入上限。

## 2. `String` 与 `&str` 的转换

### 2.1 从 `String` 借用为 `&str`

```rust
fn print_message(message: &str) {
    println!("{message}");
}

let message = String::from("hello");

print_message(&message);          // 自动解引用转换。
print_message(message.as_str()); // 显式转换。

assert_eq!(message, "hello");
```

只读取字符串的函数参数通常应写成 `&str`，这样既能接收 `String` 的借用，也能接收字符串字面量和字符串切片。

### 2.2 从 `&str` 获得拥有所有权的字符串

```rust
let borrowed = "hello";
let owned = borrowed.to_owned();

assert_eq!(owned, "hello");
```

这会分配内存并复制内容。只有确实需要独立所有权时才转换；只读场景继续使用 `&str` 即可。

### 2.3 消费 `String` 获得字节

```rust
let text = String::from("Rust");
let bytes = text.into_bytes();

assert_eq!(bytes, vec![82, 117, 115, 116]);
// text 已被消费。
```

只想查看字节而不消费字符串时，使用 `as_bytes()`：

```rust
let text = String::from("Rust");
assert_eq!(text.as_bytes(), &[82, 117, 115, 116]);
assert_eq!(text, "Rust");
```

## 3. 长度、容量与判空

### 3.1 `len()` 返回字节数

```rust
assert_eq!("hello".len(), 5);
assert_eq!("你好".len(), 6);
assert_eq!("🦀".len(), 4);
```

Rust 字符串使用 UTF-8 编码，所以 `len()` 返回字节数。它不一定等于 Unicode 标量值数量，更不一定等于用户看到的字符数量。

计算 Unicode 标量值数量可以使用 `chars().count()`：

```rust
assert_eq!("你好".chars().count(), 2);
assert_eq!("🦀".chars().count(), 1);
```

但一个用户感知字符（字形簇）可能由多个 Unicode 标量值组成。例如带组合符号的字符、部分 emoji 和旗帜。标准库不直接提供字形簇切分；需要时应使用专门的 Unicode 库。

### 3.2 `is_empty()` 判断是否为空

```rust
let empty = String::new();

assert!(empty.is_empty());
assert_eq!(empty.len(), 0);
```

表达判空意图时，`is_empty()` 通常比 `len() == 0` 更清晰。

### 3.3 容量管理

```rust
let mut text = String::with_capacity(10);
text.push_str("hello");

assert_eq!(text.len(), 5);
assert!(text.capacity() >= 10);

text.reserve(20);
assert!(text.capacity() >= text.len() + 20);

text.shrink_to_fit();
assert!(text.capacity() >= text.len());
```

- `len()` 是当前内容的字节数；
- `capacity()` 是不重新分配时最多可以容纳的字节数；
- `reserve(n)` 确保至少还能增加 `n` 字节；
- `shrink_to_fit()` 尝试释放多余容量，但不保证容量一定等于长度。

不要频繁调用 `shrink_to_fit()`，重新分配本身也有成本。

## 4. 遍历字符串

### 4.1 使用 `chars()` 遍历 Unicode 标量值

```rust
let chars: Vec<char> = "Rust🦀".chars().collect();

assert_eq!(chars, vec!['R', 'u', 's', 't', '🦀']);
```

`char` 表示一个 Unicode 标量值，固定占 4 字节；它不等同于 UTF-8 中的单个字节，也不总是等同于用户看到的一个完整字符。

取得首尾字符：

```rust
let text = "Rust🦀";

assert_eq!(text.chars().next(), Some('R'));
assert_eq!(text.chars().next_back(), Some('🦀'));
```

### 4.2 使用 `bytes()` 遍历 UTF-8 字节

```rust
let bytes: Vec<u8> = "é".bytes().collect();
assert_eq!(bytes, vec![0xC3, 0xA9]);
```

只有在处理协议、编码、ASCII 或底层字节时才应使用 `bytes()`。不要把每个 UTF-8 字节当作一个字符。

### 4.3 使用 `char_indices()` 同时取得字节位置

```rust
let positions: Vec<(usize, char)> = "a你b".char_indices().collect();

assert_eq!(positions, vec![(0, 'a'), (1, '你'), (4, 'b')]);
```

返回的索引是该字符在 UTF-8 字符串中的**字节偏移量**，可以用于合法的字符串切片或修改操作。

## 5. 查找与判断

### 5.1 `contains`、`starts_with` 和 `ends_with`

```rust
let text = "hello, Rust";

assert!(text.contains("Rust"));
assert!(text.starts_with("hello"));
assert!(text.ends_with("Rust"));
assert!(!text.contains("Go"));
```

这些方法区分大小写，并按字符串内容匹配。

它们也可以接受某些字符模式：

```rust
let text = "report.csv";

assert!(text.ends_with(['v', 't']));
assert!(text.contains(|character: char| character.is_ascii_digit()) == false);
```

### 5.2 `find` 和 `rfind`

`find` 返回第一次匹配的字节位置，`rfind` 返回最后一次匹配的字节位置：

```rust
let text = "bananas";

assert_eq!(text.find("ana"), Some(1));
assert_eq!(text.rfind("ana"), Some(3));
assert_eq!(text.find("rust"), None);
```

返回类型是 `Option<usize>`，因为目标可能不存在。不要直接 `unwrap()` 外部输入的查找结果。

对非 ASCII 文本，位置仍然是字节索引：

```rust
let text = "你好，Rust";
assert_eq!(text.find("Rust"), Some(9));
```

“你”“好”和中文逗号各占 3 个 UTF-8 字节，因此 `Rust` 从字节位置 9 开始。

### 5.3 `matches` 和 `match_indices`

```rust
let text = "red,green,red";

let matches: Vec<_> = text.matches("red").collect();
let positions: Vec<_> = text.match_indices("red").collect();

assert_eq!(matches, vec!["red", "red"]);
assert_eq!(positions, vec![(0, "red"), (10, "red")]);
```

它们适合遍历所有非重叠匹配项。复杂模式或正则表达式需要使用专门的正则库。

## 6. 安全切片与索引

### 6.1 Rust 不允许使用整数直接索引字符串

下面的代码不能编译：

```rust,compile_fail
let text = String::from("hello");
let first = text[0];
```

原因是 UTF-8 字符具有可变字节长度，“第 0 个元素”可能表示字节、Unicode 标量值或用户感知字符，语义并不明确。

### 6.2 按字节边界切片

可以使用字节范围取得 `&str`：

```rust
let text = "hello";
assert_eq!(&text[0..2], "he");
```

但是范围越界或落在 UTF-8 字符内部会 panic：

```rust,should_panic
let text = "你好";
let _invalid = &text[0..1]; // “你”占 3 字节。
```

处理不可信索引时，优先使用 `get`，失败时返回 `None`：

```rust
let text = "你好";

assert_eq!(text.get(0..3), Some("你"));
assert_eq!(text.get(0..1), None);
assert_eq!(text.get(100..200), None);
```

可以用 `is_char_boundary` 检查某个字节位置是否为 UTF-8 字符边界：

```rust
let text = "你a";

assert!(text.is_char_boundary(0));
assert!(!text.is_char_boundary(1));
assert!(text.is_char_boundary(3));
assert!(text.is_char_boundary(4));
```

### 6.3 按字符数量截取

如果业务需要取得前几个 Unicode 标量值，可以通过 `chars()`：

```rust
let text = "你好 Rust";
let first_two: String = text.chars().take(2).collect();

assert_eq!(first_two, "你好");
```

这会创建新的 `String`。如果需要返回切片并避免分配，可以通过 `char_indices()` 找到对应的字节边界：

```rust
fn first_chars(text: &str, count: usize) -> &str {
    let end = text
        .char_indices()
        .nth(count)
        .map_or(text.len(), |(index, _character)| index);
    &text[..end]
}

assert_eq!(first_chars("你好 Rust", 2), "你好");
assert_eq!(first_chars("Rust", 20), "Rust");
```

这里仍按 Unicode 标量值计数，不是按字形簇计数。

## 7. 分割字符串

### 7.1 `split`

```rust
let fields: Vec<_> = "red,green,blue".split(',').collect();

assert_eq!(fields, vec!["red", "green", "blue"]);
```

连续分隔符会产生空字段：

```rust
let fields: Vec<_> = "a,,b,".split(',').collect();
assert_eq!(fields, vec!["a", "", "b", ""]);
```

如果只想分割有限次数，使用 `splitn`：

```rust
let parts: Vec<_> = "key=value=extra".splitn(2, '=').collect();
assert_eq!(parts, vec!["key", "value=extra"]);
```

### 7.2 `split_once`

只需分为左右两部分时，`split_once` 比收集到 `Vec` 更直接：

```rust
fn parse_assignment(input: &str) -> Option<(&str, &str)> {
    input.split_once('=')
}

assert_eq!(parse_assignment("name=Alice"), Some(("name", "Alice")));
assert_eq!(parse_assignment("invalid"), None);
```

从右侧分割一次可以使用 `rsplit_once`。

### 7.3 `split_whitespace`

```rust
let words: Vec<_> = "  Rust\n is\tfast  ".split_whitespace().collect();

assert_eq!(words, vec!["Rust", "is", "fast"]);
```

`split_whitespace` 会识别 Unicode 空白、合并连续空白，并忽略开头和结尾的空白。它不同于 `split(' ')`：

```rust
let fields: Vec<_> = " a  b ".split(' ').collect();
assert_eq!(fields, vec!["", "a", "", "b", ""]);
```

### 7.4 `lines`

```rust
let lines: Vec<_> = "first\nsecond\r\nthird\n".lines().collect();

assert_eq!(lines, vec!["first", "second", "third"]);
```

`lines()` 不包含行尾符，也不会为末尾换行额外产生一个空行。需要保留或精确处理行尾符时，应选择更合适的分割方式。

## 8. 去除首尾内容

### 8.1 `trim` 系列

```rust
let text = " \n\t hello \r\n";

assert_eq!(text.trim(), "hello");
assert_eq!(text.trim_start(), "hello \r\n");
assert_eq!(text.trim_end(), " \n\t hello");
```

这些方法返回原字符串的切片，不会修改原字符串，也不会分配新字符串。

### 8.2 `trim_matches`

```rust
let text = "...hello...";

assert_eq!(text.trim_matches('.'), "hello");
assert_eq!(text.trim_start_matches('.'), "hello...");
assert_eq!(text.trim_end_matches('.'), "...hello");
```

还可以传入判断闭包：

```rust
let text = "123hello456";
let trimmed = text.trim_matches(|character: char| character.is_ascii_digit());

assert_eq!(trimmed, "hello");
```

`trim_matches` 会反复移除首尾所有匹配项，而不是只移除一次。

### 8.3 `strip_prefix` 和 `strip_suffix`

只想移除一个确定的前缀或后缀时，使用返回 `Option<&str>` 的方法：

```rust
let path = "/api/users";
let file = "report.csv";

assert_eq!(path.strip_prefix("/api/"), Some("users"));
assert_eq!(file.strip_suffix(".csv"), Some("report"));
assert_eq!(file.strip_suffix(".json"), None);
```

不要先调用 `starts_with` 再手动切片；`strip_prefix` 可以在一次操作中完成检查和提取。

## 9. 替换字符串内容

### 9.1 `replace` 和 `replacen`

```rust
let text = "red green red";

assert_eq!(text.replace("red", "blue"), "blue green blue");
assert_eq!(text.replacen("red", "blue", 1), "blue green red");
```

这两个方法返回新的 `String`，不会修改原字符串。

### 9.2 `replace_range`

`String::replace_range` 会原地替换一个合法的字节范围：

```rust
let mut text = String::from("hello Rust");
text.replace_range(0..5, "Hi");

assert_eq!(text, "Hi Rust");
```

范围必须位于字符边界，否则会 panic。处理外部索引时应先校验。

## 10. 修改 `String`

### 10.1 `push` 与 `push_str`

```rust
let mut text = String::from("Rust");

text.push('!');       // 添加一个 char。
text.push_str(" 🦀"); // 添加一个 &str。

assert_eq!(text, "Rust! 🦀");
```

`push` 接收一个 `char`，`push_str` 接收 `&str`。`push_str` 只借用参数，不会取得参数的所有权：

```rust
let suffix = String::from(" language");
let mut text = String::from("Rust");

text.push_str(&suffix);

assert_eq!(text, "Rust language");
assert_eq!(suffix, " language");
```

### 10.2 `insert` 与 `insert_str`

```rust
let mut text = String::from("Rst");
text.insert(1, 'u');

assert_eq!(text, "Rust");

text.insert_str(4, " language");
assert_eq!(text, "Rust language");
```

索引是字节位置，并且必须位于 UTF-8 字符边界。字符串中间插入需要移动后续字节，频繁执行可能较慢。

### 10.3 `pop` 与 `remove`

`pop` 删除并返回最后一个 Unicode 标量值：

```rust
let mut text = String::from("Rust🦀");

assert_eq!(text.pop(), Some('🦀'));
assert_eq!(text, "Rust");
```

`remove` 删除指定字节位置开始的一个 `char`：

```rust
let mut text = String::from("R🦀ust");

let removed = text.remove(1);

assert_eq!(removed, '🦀');
assert_eq!(text, "Rust");
```

位置必须是字符边界。`remove` 需要移动后续内容，不适合反复从长字符串开头删除字符。

### 10.4 `truncate` 与 `clear`

```rust
let mut text = String::from("hello world");
text.truncate(5);
assert_eq!(text, "hello");

text.clear();
assert!(text.is_empty());
```

`truncate` 参数是字节长度，必须位于字符边界；`clear` 删除全部内容，但通常保留已分配容量以便复用。

### 10.5 `retain`

`retain` 原地保留满足条件的 `char`：

```rust
let mut text = String::from("a1你2b3");
text.retain(|character| !character.is_ascii_digit());

assert_eq!(text, "a你b");
```

闭包按 Unicode 标量值执行。它适合简单字符过滤，不适合需要识别完整字形簇的逻辑。

## 11. 拼接字符串

### 11.1 使用 `+`

```rust
let left = String::from("hello, ");
let right = String::from("Rust");

let combined = left + &right;

assert_eq!(combined, "hello, Rust");
assert_eq!(right, "Rust");
// left 已被移动，不能继续使用。
```

`String + &str` 会取得左侧 `String` 的所有权，并借用右侧字符串。它适合少量简单拼接，但连续使用可能不够清晰。

### 11.2 使用 `format!`

```rust
let language = String::from("Rust");
let year = 2015;

let message = format!("{language} 1.0 released in {year}");

assert_eq!(message, "Rust 1.0 released in 2015");
assert_eq!(language, "Rust");
```

`format!` 适合组合多个不同类型的值，写法可读，也不会取得这些参数的所有权。它会创建新的 `String`。

### 11.3 使用 `push_str` 高效构建

循环中不断构建字符串时，可以预分配后使用 `push_str`：

```rust
let words = ["Rust", "is", "fast"];
let mut sentence = String::with_capacity(16);

for (index, word) in words.iter().enumerate() {
    if index > 0 {
        sentence.push(' ');
    }
    sentence.push_str(word);
}

assert_eq!(sentence, "Rust is fast");
```

### 11.4 使用 `join` 和 `concat`

```rust
let words = ["Rust", "is", "fast"];

assert_eq!(words.join(" "), "Rust is fast");
assert_eq!(words.concat(), "Rustisfast");
```

`join` 在元素之间插入分隔符，`concat` 直接连接所有内容。

## 12. 大小写转换

### 12.1 Unicode 大小写转换

```rust
assert_eq!("Rust".to_lowercase(), "rust");
assert_eq!("Rust".to_uppercase(), "RUST");
assert_eq!("straße".to_uppercase(), "STRASSE");
```

`to_lowercase` 和 `to_uppercase` 返回新的 `String`。Unicode 大小写映射可能改变字符数量，因此不能简单地按单个字符一一替换。

### 12.2 ASCII 大小写操作

```rust
let mut text = String::from("Rust-123");
text.make_ascii_uppercase();
assert_eq!(text, "RUST-123");

text.make_ascii_lowercase();
assert_eq!(text, "rust-123");
```

`make_ascii_uppercase` 和 `make_ascii_lowercase` 原地修改，只处理 ASCII 字母。返回新字符串的版本是 `to_ascii_uppercase` 和 `to_ascii_lowercase`。

忽略 ASCII 大小写比较可以使用：

```rust
assert!("Content-Type".eq_ignore_ascii_case("content-type"));
```

它只适合 ASCII 语义，例如部分协议字段。完整的 Unicode 无大小写匹配比简单转小写复杂，可能需要专门库和明确的本地化规则。

## 13. 解析与格式化

### 13.1 使用 `parse` 将字符串转换为其他类型

```rust
let port: u16 = "8080".parse().expect("端口应是有效的 u16");
assert_eq!(port, 8080);
```

对外部输入应处理解析错误：

```rust
fn parse_port(text: &str) -> Result<u16, std::num::ParseIntError> {
    text.trim().parse::<u16>()
}

assert_eq!(parse_port(" 8080 "), Ok(8080));
assert!(parse_port("invalid").is_err());
```

`parse::<T>()` 要求目标类型实现 `FromStr`。目标类型既可以通过变量标注，也可以通过 turbofish 语法 `::<T>` 指定。

### 13.2 使用 `format!` 转成字符串

```rust
let name = "Alice";
let score = 95;

let message = format!("{name}: {score:03}");
assert_eq!(message, "Alice: 095");
```

常用格式包括：

```rust
assert_eq!(format!("{:>5}", 42), "   42"); // 右对齐
assert_eq!(format!("{:<5}", 42), "42   "); // 左对齐
assert_eq!(format!("{:.2}", 3.14159), "3.14"); // 小数精度
assert_eq!(format!("{:#x}", 255), "0xff"); // 十六进制
```

`.to_string()` 适合单个实现 `Display` 的值，`format!` 适合包含模板、多个值或格式要求的场景。

## 14. 从字节创建字符串

### 14.1 `String::from_utf8`

```rust
let bytes = vec![82, 117, 115, 116];
let text = String::from_utf8(bytes).expect("字节应是合法 UTF-8");

assert_eq!(text, "Rust");
```

输入无效时返回 `FromUtf8Error`，不会创建非法的 Rust 字符串：

```rust
let invalid = String::from_utf8(vec![0xFF]);
assert!(invalid.is_err());
```

### 14.2 `String::from_utf8_lossy`

需要容忍无效 UTF-8 时，可以用替换字符 `�` 代替无效序列：

```rust
use std::borrow::Cow;

let valid = String::from_utf8_lossy(b"Rust");
let invalid = String::from_utf8_lossy(&[b'R', 0xFF, b't']);

assert!(matches!(valid, Cow::Borrowed("Rust")));
assert_eq!(invalid, "R�t");
```

返回类型是 `Cow<'_, str>`：输入有效时可以直接借用原字节，无效时才需要分配新的字符串。

不要在不能证明字节一定合法时使用未经检查的 UTF-8 转换。错误使用 `unsafe` 会破坏 `String` 必须是合法 UTF-8 的基本不变量。

## 15. 转义与原始字符串

### 15.1 常用转义

```rust
let text = "first\nsecond\t\"quoted\"";

assert!(text.contains('\n'));
assert!(text.contains('\t'));
assert!(text.contains("\"quoted\""));
```

常见转义包括 `\n`、`\r`、`\t`、`\\`、`\"` 和 Unicode 转义 `\u{1F980}`。

### 15.2 原始字符串字面量

原始字符串中反斜杠通常不需要转义：

```rust
let windows_path = r"C:\Users\Alice";
let json = r#"{"name":"Alice"}"#;

assert_eq!(windows_path, "C:\\Users\\Alice");
assert_eq!(json, "{\"name\":\"Alice\"}");
```

当内容本身包含 `"#` 时，可以增加外围 `#` 的数量。原始字符串适合正则表达式、JSON 片段和 Windows 路径等包含大量反斜杠或引号的文本。

## 16. 比较与排序

```rust
assert_eq!("Rust", String::from("Rust"));
assert!("apple" < "banana");
```

Rust 字符串默认按 UTF-8/Unicode 标量值对应的字典顺序比较，不是自然语言中的本地化排序规则。

忽略 ASCII 大小写时可以使用 `eq_ignore_ascii_case`。涉及中文拼音、重音符号、区域规则或自然语言排序时，需要专门的 Unicode 排序库和明确的 locale。

还应注意，视觉上相同的 Unicode 文本可能具有不同的编码序列：

```rust
let composed = "é";       // U+00E9
let decomposed = "e\u{301}"; // U+0065 + U+0301

assert_ne!(composed, decomposed);
```

标准字符串相等比较不会自动进行 Unicode 规范化。用户名、搜索或跨系统文本比较如果需要规范等价，应选择一种规范化形式并使用专门的 Unicode 库。

## 17. API 设计与性能建议

### 17.1 输入参数优先使用 `&str`

```rust
fn is_rust_file(filename: &str) -> bool {
    filename.ends_with(".rs")
}

let owned = String::from("main.rs");

assert!(is_rust_file(&owned));
assert!(is_rust_file("lib.rs"));
```

如果函数只读取文本，接收 `&str` 通常比接收 `&String` 更通用，也比接收 `String` 更少限制调用者。

### 17.2 返回值根据所有权需求选择

- 返回输入的一部分：优先返回与输入生命周期关联的 `&str`；
- 返回新构造或需要独立存活的文本：返回 `String`；
- 有时借用、有时需要创建：可以考虑 `Cow<'a, str>`；
- 固定不变的程序内文本：可以返回 `&'static str`。

```rust
fn extension(filename: &str) -> Option<&str> {
    filename.rsplit_once('.').map(|(_name, extension)| extension)
}

assert_eq!(extension("archive.tar.gz"), Some("gz"));
assert_eq!(extension("README"), None);
```

### 17.3 避免循环中的无意义分配

频繁使用 `result = result + piece`、在只读场景反复 `to_string()`，或者为了满足借用而盲目 `clone()`，都可能产生不必要的分配和复制。

构建较长字符串时通常可以：

- 预估大小并调用 `String::with_capacity`；
- 使用 `push` 和 `push_str`；
- 对列表使用 `join`；
- 复杂格式使用 `write!` 写入已有 `String`。

```rust
use std::fmt::Write;

let mut output = String::new();

for number in 1..=3 {
    write!(&mut output, "#{number} ").expect("写入 String 不会失败");
}

assert_eq!(output, "#1 #2 #3 ");
```

### 17.4 注意算法复杂度

UTF-8 字符是变长编码，按第 `n` 个字符访问通常需要从前向后遍历，因此不是常数时间。如果业务需要频繁按位置访问 Unicode 标量值，可以考虑预先收集为 `Vec<char>`；如果只处理 ASCII 或原始数据，字节切片可能更合适。

但 `Vec<char>` 会增加内存占用，并且仍不能正确表示用户感知的字形簇。应根据真实语义选择表示方式。

## 18. 常见错误清单

1. **认为 `len()` 返回字符数**：它返回 UTF-8 字节数。
2. **尝试使用 `text[0]` 获取首字符**：Rust 不支持整数索引字符串，使用 `chars().next()`。
3. **用未经验证的字节范围切片**：范围越界或不在字符边界会 panic，外部索引使用 `get`。
4. **把 `char` 当作用户看到的完整字符**：一个字形簇可能包含多个 Unicode 标量值。
5. **用 `split(' ')` 解析任意空白**：通常应使用 `split_whitespace()`。
6. **先 `starts_with` 再手动切片**：可以直接使用 `strip_prefix`。
7. **使用 `+` 后继续访问左侧 `String`**：左侧所有权已经移动。
8. **只读函数接收 `&String` 或 `String`**：通常接收 `&str` 更灵活。
9. **循环中反复创建临时 `String`**：考虑预分配并使用 `push_str` 或 `write!`。
10. **假设转小写后就能正确进行所有语言的无大小写比较**：Unicode 和本地化规则更加复杂。
11. **认为视觉相同的文本一定相等**：可能需要 Unicode 规范化。
12. **盲目使用未经检查的 UTF-8 转换**：这会破坏字符串类型的不变量。

## 19. 一个完整示例

下面的函数解析形如 `host:port` 的地址，去除两侧空白，验证主机名和端口，并返回拥有所有权的配置：

```rust
#[derive(Debug, PartialEq, Eq)]
struct Endpoint {
    host: String,
    port: u16,
}

#[derive(Debug, PartialEq, Eq)]
enum ParseEndpointError {
    MissingSeparator,
    EmptyHost,
    InvalidPort,
    ZeroPort,
}

fn parse_endpoint(input: &str) -> Result<Endpoint, ParseEndpointError> {
    let (host_text, port_text) = input
        .trim()
        .rsplit_once(':')
        .ok_or(ParseEndpointError::MissingSeparator)?;

    let host = host_text.trim();
    if host.is_empty() {
        return Err(ParseEndpointError::EmptyHost);
    }

    let port = port_text
        .trim()
        .parse::<u16>()
        .map_err(|_error| ParseEndpointError::InvalidPort)?;

    if port == 0 {
        return Err(ParseEndpointError::ZeroPort);
    }

    Ok(Endpoint {
        host: host.to_owned(),
        port,
    })
}

fn main() {
    assert_eq!(
        parse_endpoint(" api.example.com : 8080 "),
        Ok(Endpoint {
            host: String::from("api.example.com"),
            port: 8080,
        })
    );

    assert_eq!(
        parse_endpoint("api.example.com"),
        Err(ParseEndpointError::MissingSeparator)
    );
    assert_eq!(parse_endpoint(":8080"), Err(ParseEndpointError::EmptyHost));
    assert_eq!(
        parse_endpoint("localhost:abc"),
        Err(ParseEndpointError::InvalidPort)
    );
    assert_eq!(
        parse_endpoint("localhost:0"),
        Err(ParseEndpointError::ZeroPort)
    );
}
```

这个示例综合使用了：

- `trim()` 去除输入两侧和字段两侧的空白；
- `rsplit_once(':')` 从右侧将地址拆成两部分；
- `is_empty()` 检查主机名；
- `parse::<u16>()` 解析端口；
- `to_owned()` 只在最终需要独立保存主机名时分配字符串；
- `Result` 和 `?` 保留并传播具体错误。

## 总结

正确使用 Rust 字符串，应始终记住以下原则：

- `String` 拥有数据，`&str` 借用一段合法 UTF-8 文本；
- `len()` 和字符串索引使用字节语义，不是字符语义；
- 遍历文本根据需求选择 `bytes()`、`chars()` 或字形簇处理库；
- 处理外部字节索引时使用 `get`，避免因非法字符边界而 panic；
- 只读参数优先接受 `&str`，只有需要独立所有权时才创建 `String`；
- 分割、查找和解析方法经常返回 `Option` 或 `Result`，应认真处理失败；
- 构建长字符串时预分配并复用缓冲区；
- 涉及自然语言比较、规范化或字形簇时，不要把 UTF-8 字节或 `char` 当作完整答案。

掌握这些方法和边界后，Rust 的字符串处理会变得安全、明确且高效。
